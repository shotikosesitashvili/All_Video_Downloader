# All Video Downloader — Telegram ბოტი

ქართული Telegram ბოტი YouTube, TikTok, Facebook, Instagram და yt-dlp-ის მიერ მხარდაჭერილი სხვა საიტებისთვის.

## შესაძლებლობები

- ბმულის შემოწმება და რეალურად ნაპოვნი გარჩევადობების ღილაკები.
- არჩეულ სიმაღლემდე საუკეთესო ვიდეო და ხმა; საუკეთესო ხარისხის ცალკე ღილაკი.
- MP3 აუდიო (192 kbps).
- ვიდეო იგზავნება ფაილად (MP4/WebM/MKV), ორიგინალის კოდეკის შენარჩუნებით; MP3 — აუდიოდ.
- ქართული მენიუ, რიგი, თითო მომხმარებელზე ერთი აქტიური მოთხოვნა, სულ ორი ერთდროული სამუშაო.
- 15 წუთში მოძველებული ღილაკები ითიშება; ჩამოტვირთული ფაილები დასრულებისას იშლება.
- მომხმარებლების სია, კერძო ჩატი, timeout და ცალკე ჩამომტვირთავი პროცესი.

**ყველა ვიდეოს ჩამოტვირთვა შეუძლებელია.** პირადი, DRM-ით დაცული, გეოგრაფიულად შეზღუდული ან ავტორიზაციის მომთხოვნი მასალა შეიძლება არ მუშაობდეს. პირდაპირი ეთერი და playlist-ები არ მხარდაჭერება. ჩვეულებრივ ვებგვერდზე ვიდეო yt-dlp-მ უნდა აღმოაჩინოს. YouTube-ის ბოტების შემოწმებამ შეიძლება დაბლოკოს ჰოსტინგის IP. პროექტი შეზღუდვების გვერდის ავლას არ ახორციელებს.

## სად ჩავწერო BotFather-ის კოდი?

1. Telegram-ში გახსენი ოფიციალური [@BotFather](https://t.me/BotFather).
2. გაგზავნე `/newbot`, შეარჩიე სახელი და username.
3. მიღებული **ტოკენი** ჩაწერე **.env** ფაილში, `BOT_TOKEN=` შემდეგ.
4. `.env.example` გადააკოპირე `.env` სახელით პროექტის მთავარ საქაღალდეში:

```dotenv
BOT_TOKEN=აქ_ჩასვი_BotFather_ის_ტოკენი
ALLOWED_USER_IDS=
MAX_FILE_MB=49
JOB_TIMEOUT_SECONDS=600
```

ტოკენი არ ჩასვა Python კოდში, GitHub-ში ან README-ში. `.env` Git-ისა და Docker build-ის გამორიცხვის სიაშია.

## გაშვება Docker-ით (რეკომენდებულია)

დააყენე Docker Desktop (Windows/macOS) ან Docker Engine + Compose (Linux).

```bash
git clone https://github.com/shotikosesitashvili/All_Video_Downloader.git
cd All_Video_Downloader
```

PowerShell:
```powershell
Copy-Item .env.example .env
notepad .env
docker compose up -d --build
```

Linux/macOS:
```bash
cp .env.example .env
# გახსენი .env რედაქტორში და ჩაწერე ტოკენი
docker compose up -d --build
```

შემდეგ:
1. გახსენი შენი ბოტი Telegram-ში და გაგზავნე `/id`.
2. მიღებული რიცხვი ჩასვი `.env`-ში: `ALLOWED_USER_IDS=123456789`.
3. გადატვირთე: `docker compose up -d --force-recreate`.
4. გაგზავნე `/start`, ვიდეოს ბმული და აირჩიე ხარისხი.

რამდენიმე მომხმარებელი: `ALLOWED_USER_IDS=123456789,987654321`.
ცარიელი სიისას ჩამოტვირთვა ყველასთვის დაკეტილია, მაგრამ `/id` მუშაობს.
ბოტი მხოლოდ კერძო ჩატში ჩამოტვირთავს.

ლოგები: `docker compose logs --tail=50 -f`
გაჩერება: `docker compose down`

## გაშვება Python-ით

საჭიროა Python 3.12+, FFmpeg და Node.js (YouTube-ის JavaScript ამოცანებისთვის), სამივე PATH-ში.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
.venv\Scripts\python bot.py
```

Linux/macOS-ზე გამოიყენე `.venv/bin/python`. მომხმარებლის ID-ის დამატების შემდეგ ბოტი თავიდან გაუშვი.

## ლიმიტები და ჰოსტინგი

[Telegram-ის ჩვეულებრივი Bot API](https://core.telegram.org/bots/api#sending-files) ატვირთვას 50 MB-მდე უშვებს. ბოტი იყენებს მაქსიმუმ 49 MB-ს; უფრო დიდი ვიდეოსთვის აირჩიე დაბალი ხარისხი ან მოკლე ვიდეო. ხარისხების ღილაკები ხელმისაწვდომ გარჩევადობებს აჩვენებს და ფაილის ზომაში ჩატევას არ იძლევა გარანტიად. უცნობი ზომის ნაკადი შეიძლება ჩამოიტვირთოს და საბოლოო შემოწმებაზე უარყოფილი იყოს. არჩეული სიმაღლე მაქსიმალური ზღვარია; 1080p-მდე შეიძლება დაბალი ხელმისაწვდომი ხარისხი აირჩეს.

GitHub კოდს ინახავს. **ბოტის 24/7 მუშაობისთვის საჭიროა მუდმივად ჩართული კომპიუტერი ან VPS**, Docker-ის მუდმივი სერვისით. GitHub Pages Python ბოტს არ გაუშვებს. გამოიყენება polling; HTTPS დომენი და შემომავალი პორტი საჭირო არ არის. ერთ ტოკენზე მხოლოდ ერთი ბოტის პროცესი გაუშვი.

პროექტი პირადი/სანდო მომხმარებლებისთვისაა. საწყისი URL-ის შიდა IP მოწმდება, მაგრამ საიტის გადამისამართებები და მედიის მისამართები სრულ ქსელურ იზოლაციას არ ქმნის. გაუშვი ცალკე ჰოსტზე, მგრძნობიარე შიდა სერვისების გარეშე; საჯარო მრავალმომხმარებლიანი სერვისისთვის დაამატე egress firewall/proxy, დისკის კვოტა და უფრო ძლიერი რიგი. Docker-ის რესურსის ლიმიტები დისკის კვოტას არ ცვლის.

საიტების ცვლილებისას განაახლე yt-dlp: `docker compose build --no-cache && docker compose up -d`.

გამოიყენე მხოლოდ იმ კონტენტისთვის, რომლის ჩამოტვირთვის უფლებაც გაქვს.
