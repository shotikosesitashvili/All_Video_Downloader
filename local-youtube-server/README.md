# YouTube ვიდეოს ჩამომტვირთავი

## Windows-ზე გაშვება

1. გახსენი ეს საქაღალდე File Explorer-ში.
2. ორჯერ დააჭირე `start.bat`-ს.
3. დაელოდე პაკეტების დაყენებას და გახსენი http://127.0.0.1:5000.
4. ჩასვი საჯარო YouTube ბმული, აირჩიე ხარისხი ან აუდიო და დააჭირე ჩამოტვირთვას.

`start.bat` იყენებს `python -m pip` ბრძანებას, რადგან ზოგიერთ Windows-ზე `pip.exe`-ს უშვებს უსაფრთხოების პოლიტიკა. FFmpeg ავტომატურად მოყვება `imageio-ffmpeg` პაკეტს; ცალკე დაყენება საჭირო არ არის.

თუ PowerShell-ში ხელით გაშვება გირჩევნია, ამ საქაღალდეში შეასრულე:

```powershell
python -m pip install -r requirements.txt
python app.py
```

პირველი გაშვებისას პაკეტების ჩამოსატვირთად ინტერნეტია საჭირო. ამ ადგილობრივ პროგრამას ჩამოტვირთვისას ჩართული კომპიუტერი სჭირდება.
